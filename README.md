# colomark_bmi                                  
Derives BMI and adiposity variables for the COLOMARK
colorectal cancer biomarker study.

Code for: Wu D. et al. (2026). *Journal*. doi:10.xxxx/xxxxx

## Overview                                      
Cleans anthropometric measurements and derives the BMI
variables used in all COLOMARK analyses, so every paper
in the project starts from the same definitions.

## Data                                          
Not included in this repository.
  data/raw/       expected input files, not distributed
  data/derived/   generated by the scripts
COLOMARK data available on application: <link>
See data/README.md for the variables expected.

## Getting started                               
R 4.4. Packages: data.table, ggplot2.
Put the raw files in data/raw/, then run:

  scripts/01_clean.R        cleans measurements
  scripts/02_derive_bmi.R   derives BMI vars   -> output/

Functions used by both live in R/bmi_functions.R.
